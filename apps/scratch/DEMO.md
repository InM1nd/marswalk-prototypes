# Scratch Card — 1-minute demo script

## Classic scratch (`/scratch/`)

1. Hub → Scratch Card.
2. Show foil ticket chrome + brand strip. Scratch with sparkles → prize punch → Claim → GDPR lead → success pipeline line.
3. DevTools filter `[analytics]` (`scratch_view`, `scratch_start`, `scratch_result`, `lead_*`).
4. **Reset demo session** → switch to **Banking** (or `?campaign=bank-demo`). Point out wash/foil/copy change.
5. Optional: Customize → prize weights %.

## Lotto (`/scratch/lotto`)

1. Same suite, match-3 mechanic.
2. Scratch tiles (soft foil + sparkles) → match highlight → lead.
3. Switch FMCG / Banking / Travel presets.
